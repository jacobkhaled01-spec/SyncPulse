# ⚡ SyncPulse Live Presentation Hub | مركز العرض والمناقشة المباشر

مركز عرض ويب تفاعلي ثلاثي الشاشات تم تصميمه خصيصاً لمناقشة مشروع التخرج أمام لجنة ومدرس مقرر **"برمجة خادم وعميل"**.

---

## 🖥️ ما يقدمه هذا المركز أثناء المناقشة:
1. **عرض الشاشات الثلاث في وقت واحد (Grid View):**
   * **الشاشة 1:** واجهة الخادم المركزي `SyncPulse.Server` (TCP 8888 / UDP 8889 / UDP Discovery 8887).
   * **الشاشة 2:** واجهة العميل الأول (أ) `SyncPulse.Client` (المتصل: سليمان).
   * **الشاشة 3:** واجهة العميل الثاني (ب) `SyncPulse.Client` (المستقبل: يعقوب).

2. **بث الشاشة الحقيقية للابتوبات (Live Screen Capture):**
   * عبر الضغط على زر **"🎥 بث الشاشة الحية"** في أي جهاز، يتم التقاط وبث شاشة اللابتوب الفعلي مباشرة إلى داخل المتصفح بأعلى دقة وبدون أي تأخير.

3. **سلاسة وسرعة التنقل باختصارات لوحة المفاتيح (Keyboard Shortcuts):**
   * **`1`**: تكبير وعرض شاشة الخادم (Server Focus).
   * **`2`**: تكبير وعرض شاشة العميل الأول (Client 1 Focus).
   * **`3`**: تكبير وعرض شاشة العميل الثاني (Client 2 Focus).
   * **`G`**: العودة لعرض الأجهزة الثلاثة معاً (Grid View).
   * **`S`**: عرض شاشتي العميلين جنباً إلى جنب (Split Comparison).
   * **`F`**: وضع ملء الشاشة (Fullscreen).
   * **`P`** أو **`I`**: فتح/إغلاق فاحص حزم البروتوكول ومسار البيانات (Packet Inspector).

4. **فاحص حزم البروتوكول اللحظي (Packet Inspector - 12-Byte FrameHeader):**
   * يعرض جدول الحزم المتبادلة برمجياً مع ترويسة الـ Hex ومسار الحزمة المتحرك من العميل إلى السيرفر إلى العميل الآخر.

---

## 🚀 طريقة التشغيل:
فقط افتح ملف **`SyncPulse.Web/index.html`** مباشرة في أي متصفح ويب حديث (Google Chrome, Microsoft Edge, Firefox, Brave) بالنقر المزدوج عليه!
