# 🚀 دليل التشغيل السريع للأجهزة الثلاثة يوم المناقشة (SyncPulse 3-Device Live Run)

---

## 💻 تجهيز الأجهزة الثلاثة على نفس شبكة الواي فاي (Local WiFi / Hotspot)
> [!IMPORTANT]
> تأكد من اتصال الأجهزة الثلاثة بنفس شبكة الواي فاي (أو نقطة اتصال Hotspot من الجوال). لا يُشترط وجود إنترنت نهائياً!

---

### 1️⃣ الجهاز الأول (Laptop 1 - الخادم المركزي):
1. انسخ مجلد `Device_1_Server` إلى الجهاز 1.
2. شغّل الملف: **`SyncPulse.Server.exe`**.
3. ستفتح شاشة لوحة تحكم الخادم وسيظهر عنوان IP المحلي (مثلاً `192.168.1.50`).
4. يبدأ الخادم بالاستماع على:
   - **TCP Port 8888** (المصادقة والرسائل وإشارات المكالمات).
   - **UDP Port 8889** (مكرر تدفقات الصوت والفيديو).
   - **UDP Port 8887** (بث الاكتشاف التلقائي على الواي فاي).

---

### 2️⃣ الجهاز الثاني (Laptop 2 - العميل A):
1. انسخ مجلد `Device_2_Client_A` إلى الجهاز 2.
2. شغّل الملف: **`SyncPulse.Client.exe`**.
3. اضغط على زر **"اكتشاف تلقائي (Auto-Discovery)"** ليلتقط IP الخادم فوراً (أو اكتب IP الخادم يدوياً).
4. سجّل الدخول باسم مستخدم (مثلاً `engineer_1` أو `client_a`).

---

### 3️⃣ الجهاز الثالث (Laptop 3 - العميل B):
1. انسخ مجلد `Device_3_Client_B` إلى الجهاز 3.
2. شغّل الملف: **`SyncPulse.Client.exe`**.
3. اضغط على زر **"اكتشاف تلقائي (Auto-Discovery)"** ليلتقط IP الخادم فوراً.
4. سجّل الدخول باسم مستخدم آخر (مثلاً `engineer_2` أو `client_b`).

---

### 🌐 شاشة العرض والمراقبة المباشرة أثناء المناقشة:
* على جهاز العرض الموصول بالبروجكتر، افتح الملف:
  👉 **`SyncPulse.Web/index.html`**
* يتيح هذا المركز مشاركة شاشات الأجهزة الثلاثة وعرض تدفق البايتات الحية وسجلات الحزم التفاعلية أمام لجنة المناقشة!
