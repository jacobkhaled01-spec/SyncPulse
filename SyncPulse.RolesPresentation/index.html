المحاور الهندسية الأربعة التي يستعرضها المتحدث الأول:
1. المشكلة والدافع الأساسي

الاستغناء الكامل عن خوادم Cloud الخارجية وعمل النظام محلياً 100% On-Premise LAN دون إنترنت لحماية الخصوصية ومواصلة الاتصال عند انقطاع الـ WAN.

2. دورة حياة مقابس TCP (Socket API)

شرح تسلسل السيرفر: Socket -> Bind -> Listen -> AcceptAsync والعميل: ConnectAsync -> SendAsync -> ReceiveAsync ومصافحة 3-Way Handshake.

3. بروتوكول التأطير الثنائي 12-Byte Header

Magic Byte 0x53 ('S')، رقم الإصدار، نوع الحزمة، وطول الحمولة بدقة مع ترتيب Big-Endian وآلة الحالة FrameStreamParser لفك التجزئة.

4. الاكتشاف التلقائي Zero-Config UDP 8887

بث الخادم نبضة تعريفية كل 3 ثوانٍ على 255.255.255.255:8887 ليلتقطها العميل ويتصل فورياً دون كتابة عنوان IP يدوياً نهائياً.

المحاور الهندسية الأربعة التي يستعرضها المتحدث الثاني:
1. تجزئة كلمات المرور (NIST SP 800-63B)

استخدام PBKDF2/SHA-256 بـ 100,000 دورة تكرار مع ملح عشوائي 128-bit Salt فريد لكل مستخدم لمنع هجمات جداول قوس قزح (Rainbow Tables).

2. مناعة هجمات التوقيت (Timing Attacks)

تطبيق دالة FixedTimeEquals لمقارنة الهاشات بعملية XOR في زمن ثابت، ومنع المخترق من استنتاج كلمة المرور بقياس زمن الرد بالنانوثانية.

3. إدارة الجلسات اللامركزية (JWT RFC 7519)

توليد توكنات JWT موقعة رقمياً بـ HMAC-SHA256 تحمل معرّف المستخدم وتاريخ الصلاحية، ويتم التحقق من التوقيع في الذاكرة دون استعلام قاعدة البيانات.

4. التحصين ضد الحقن وسجلات التدقيق

حظر حقن SQL تماماً عبر Parameterized Queries، وتوثيق كافة محاولات الدخول وعناوين IP في جدول SERVER_AUDIT_LOGS وفق ISO 27001.

المحاور الهندسية الأربعة التي يستعرضها المتحدث الثالث:
1. خادم المقابس وعزل الأعطال (IOCP Async)

استماع غير حاجب على المنفذ TCP 8888، وتطبيق Bulkhead Pattern في نطاق معزول تماماً لمنع حدوث أي انهيار متسلسل (Cascading Failure).

2. قاعدة بيانات SQLite 3NF ووضع WAL

تصميم 7 جداول مترابطة بمفاتيح أجنبية، وتفعيل PRAGMA journal_mode=WAL للسماح بعدد لا نهائي من القراءات المتزامنة أثناء عمليات الكتابة دون أي أقفال.

3. طابور الرسائل المعلقة (Offline Queue)

حفظ الرسائل بحالة Sent = 0 عند عدم اتصال المستلم، ودفعها تلقائياً بالترتيب الزمني الصحيح فور تسجيل دخوله لتتحول إلى Delivered = 1 (✓✓).

4. كشف المقابس المعلقة (Half-Open Sockets)

معالجة الانقطاع الفيزيائي المفاجئ عبر فحص قراءات الصفر ونبضات الـ Heartbeat وإسقاط الجلسات الميتة وتحديث حالة الاتصال (Offline ⚪) فورياً.

المحاور الهندسية الأربعة التي يستعرضها المتحدث الرابع:
1. مكرر وسائط UDP Relay (منفذ 8889)

توجيه حزم الصوت والفيديو فورياً بنمط Stateless Forwarding دون فك تشفير لتحقيق سرعة توجيه تفوق البروكسي التقليدي بـ 5 أضعاف بزمن تأخير < 10ms.

2. محرك الصوت والقضاء على خطأ الذاكرة

صوت 16kHz HD Voice وحل خطأ 0xc0000005 عبر ابتكار 8 مخازن دائرية مثبتة بـ GCHandle.Alloc(Pinned) وتدويرها بـ BlockCopy بدون Garbage Collection.

3. محرك الفيديو والخصوصية الفيزيائية

التقاط الفيديو بـ AForge DirectShow مع معاينة ذاتية PiP، وإطفاء ضوء الـ LED الحقيقي للكاميرا فيزيائياً عبر SignalToStop() عند الكتم.

4. البث الهجين وإلغاء التكرار اللحظي

بث متوازي عبر UDP و TCP لتخطي جدران الحماية، وخوارزمية إلغاء التكرار عبر دمج النوع والتسلسل في مفتاح ثنائي 64-bit Timestamp.
