# 📊 SyncPulse Interactive Presentation System | نظام العرض التقديمي التفاعلي

نظام عرض تقديمي تفاعلي (Interactive Slide Deck) مصمم بنمط **Light Theme نقي وفائق الأناقة** لتقديم ومناقشة مشروع تخرج مقرر **"برمجة خادم وعميل"**.

---

## 🎨 ميزات تصميم العرض التقديمي:
1. **ألوان فاتحة نقية وعصرية (Crisp Academic Light Theme):**
   * خلفيات بيضاء بورسلينية نقية (`#FFFFFF` و `#F8FAFC`) مع تدرجات رقيقة ومريحة للعين.
   * ألوان تمييز ملكية: الأزرق الملكي (`#2563EB`)، الأخضر الزمردي (`#059669`)، والبنفسجي الداكن (`#7C3AED`).
   * خطوط عربية ولاتينية عالية الدقة والوضوح (Cairo & Outfit & JetBrains Mono).

2. **13 شريحة شاملة وتفاعلية تغطي كافة محاور المشروع والمقرر:**
   * **الشريحة 1:** الغلاف وهوية المشروع.
   * **الشريحة 2:** المشكلة والأهداف الهندسية (On-Premise vs Cloud).
   * **الشريحة 3:** معمارية النظام وفق Clean Architecture.
   * **الشريحة 4:** مقابس TCP وبروتوكول التأطير الثنائي 12-Byte مع ترتيب Big-Endian.
   * **الشريحة 5:** الاكتشاف التلقائي لشبكات الواي فاي (UDP Broadcast 8887).
   * **الشريحة 6:** الأمان وتشفير كلمات المرور بـ PBKDF2 وتوكنات JWT.
   * **الشريحة 7:** خادم TCP والتزامن بـ IOCP وقاعدة بيانات SQLite WAL Mode.
   * **الشريحة 8:** طابور الرسائل المعلقة والمزامنة التلغرامية (Offline Queue).
   * **الشريحة 9:** محرك الصوت 16kHz HD Voice ونظام المخازن الدائرية الثابتة لمنع خطأ 0xc0000005.
   * **الشريحة 10:** الفيديو المباشر AForge وإطفاء ضوء الكاميرا الحقيقي والبث الهجين.
   * **الشريحة 11:** مصفوفة توزيع المتحدثين الـ 4.
   * **الشريحة 12:** نتائج حزمة الاختبارات الآلية (62 / 62 اختبار ناجح).
   * **الشريحة 13:** الخاتمة وزر الانتقال المباشر لمركز العرض الحي للأجهزة الثلاثة!

3. **لوحة ملاحظات المتحدثين المدمجة (Speaker Notes):**
   * اضغط على زر **`📝 الملاحظات`** أو حرف **`N`** في لوحة المفاتيح لإظهار بطاقة الملاحظات الخاصة بالمتحدث للشريحة الحالية لمساعدته في الشرح الدقيق أمام اللجنة!

4. **اختصارات لوحة المفاتيح للسلاسة التامة أثناء العرض:**
   * **السهم الأيسر / المسافة / PageDown:** الانتقال للشريحة التالية.
   * **السهم الأيمن / PageUp:** العودة للشريحة السابقة.
   * **`F`:** تفعيل / إلغاء ملء الشاشة (Fullscreen).
   * **`N`:** فتح / إغلاق ملاحظات المتحدث.
   * **`M`:** فتح فهرس الشرائح والانتقال السريع لأي شريحة.
   * **`Home` / `End`:** الانتقال للشريحة الأولى / الأخيرة.
